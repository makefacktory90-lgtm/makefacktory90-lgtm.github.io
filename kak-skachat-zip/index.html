Как скачать скилл с GitHub за минуту

Вам прислали ссылку на GitHub, вы открыли, а там куча файлов, английский и ни одной понятной кнопки. Спокойно: качается всё одной кнопкой, она просто спряталась.

Шаг 1. Откройте ссылку на скилл. Вы на странице проекта: сверху название, ниже список файлов.
Шаг 2. Найдите зелёную кнопку Code (справа над списком файлов) и нажмите её.
Шаг 3. В открывшемся меню нажмите нижнюю строчку: Download ZIP. Файл уедет в загрузки.
Шаг 4. Откройте папку «Загрузки» и дважды кликните по скачанному файлу: он распакуется в обычную папку. Это и есть скилл.
Шаг 5. Дальше отдайте папку нейросети: в Claude прикрепите файлы скилла к чату (скрепка) и напишите: «Это скилл, работай по нему». Всё.

С телефона это тоже возможно, но неудобно: GitHub прячет кнопку в мобильной версии. Честный совет: делайте с компьютера, сэкономите нервы.
